# ds_learning_site

**ds** = **d**ata **s**tructures (не Data Science).
Учебный сайт-визуализатор хеш-таблицы, дерева отрезков, алгоритма Йена
и бинарной кучи на синтетическом датасете заказов маркетплейса.
С поддержкой **загрузки своего CSV** и выбора полей.

## Что внутри

- **Hash Map** — хеш-таблица с разрешением коллизий методом цепочек.
  Ключ — `unique_id`, значение — `row_id`. Поиск O(1) в среднем.
- **Segment Tree** — дерево отрезков над числовым полем, упорядоченным
  по оси (дате). Query и update за O(log n).
- **Yen's K shortest paths** — K кратчайших простых путей в графе.
  Граф: вершины — `source`, рёбра — «связаны через `target`»,
  вес — `1 / общие target`.
- **Binary Heap (MinHeap / MaxHeap)** — своя реализация бинарной кучи
  на массиве. Используется в Дейкстре (`use_own_heap=True`) для сравнения
  с `heapq` (C, stdlib).
- **Загрузка своего датасета** — `/upload`: CSV → выбор полей → выбор
  структур → прогресс-бар → работа на своих данных.
- Демо-страницы с живыми замерами и бенчмарками.

## Стек

FastAPI + Jinja2 + pandas/numpy. Индексы строятся один раз при старте
и живут в памяти всё время работы сервера. Граф кэшируется в
`data/graph_cache.pkl`, чтобы не строить его заново при каждом перезапуске.
