Замеры: Segment Tree vs Naive

Смешанная нагрузка: примерно половина операций — query(l, r), половина — update(pos, value). Naive-версия на каждый query проходит по всему диапазону, дерево — за O(log n).

Что покажет результат

  • Naive — каждый query O(длина диапазона), средняя длина при случайных l, r — примерно n/4. На 2000 операциях это десятки миллионов сложений.
  • Segment Tree — каждый query и update O(log n) ≈ 17 шагов на нашем n=120 000.
  • Ускорение — во сколько раз дерево быстрее naive на смешанной нагрузке. Ожидаемо 10–20×.
