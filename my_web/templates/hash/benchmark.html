Замеры: Hash Map vs Linear Search

Замеряем время поиска по order_id двумя способами: перебором всего списка (linear search) и через хеш-таблицу. Запросы равномерно распределены по всему датасету.

Что покажет результат

  • Linear search — O(n) на каждый запрос. При 30 запросах и 120 000 строках это ~3.6 млн сравнений.
  • Hash lookup — O(1) в среднем. Практически мгновенно на каждый запрос.
  • Ускорение — во сколько раз hash быстрее linear на этом датасете. Ожидаемо сотни-тысячи раз.
