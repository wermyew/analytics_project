О проекте

ds = data structures (не Data Science). Учебный сайт-визуализатор структур данных на синтетическом датасете заказов маркетплейса.

Что внутри

  • Hash Map — хеш-таблица с разрешением коллизий методом цепочек. Ключ — order_id, значение — номер строки в датафрейме.
  • Segment Tree — дерево отрезков над массивом total, упорядоченным по created_at. Поддерживает query и update за O(log n).

Стек

FastAPI + Jinja2 + pandas/numpy. Индексы строятся один раз при старте и живут в памяти всё время работы сервера.

Структура кода

  • core/ — чистые структуры данных, без знания про веб
  • services/ — состояние и мост между core и api
  • api/ — JSON-эндпоинты
  • pages/ — HTML-роуты
